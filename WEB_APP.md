# Веб-приложение РПД

Приложение использует Streamlit и общий граф LangGraph с узлами University, Science и Business. Для поиска и генерации используются настроенные индексы и модели Yandex AI Studio. Ключи провайдера задаются в `.env`.

## Локальная демонстрация

Откройте PowerShell в папке проекта:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Откройте [веб-приложение](http://localhost:8501). Встроенная настройка привязывает локальный запуск к `127.0.0.1`. Демонстрация открывается без учётной записи.

- **Новая РПД.** Для одной дисциплины укажите название, вуз, учебный год и известные сведения. Для комплекта введите перечень вручную или подберите его по названию курса и подтвердите отредактированный список.
- **Черновики.** Координатор сразу составляет РПД и показывает документ по разделам. Цели, задачи и предлагаемые темы он формулирует сам. Отсутствующие официальные сведения отображаются как примечание для сверки.
- **Правки и утверждение.** Под РПД находится чат для правок по инициативе преподавателя. Можно приложить до трёх файлов TXT, DOCX или PDF по 10 МБ. Кнопка «Утвердить дисциплину» утверждает текущую версию, а «Утвердить курс» утверждает текущие версии всех его РПД. Изменение текста сбрасывает утверждение этой дисциплины и всего курса. Статусы относятся к текущей сессии приложения.
- **Выгрузка.** Для дисциплины доступны JSON по `final_schema.json` и читаемый TXT. ZIP становится доступен после подготовки всех РПД курса и содержит общий `course.txt` и отдельный TXT с названием каждой дисциплины. Скачайте нужные файлы перед закрытием вкладки или перезапуском приложения.
- **Научные дополнения.** При составлении РПД агент Science подбирает материалы из Books и ищет статьи по теме дисциплины за последние 365 дней через Crossref и arXiv. По метаданным и доступным фрагментам аннотаций он предлагает темы или практические задания со ссылками. В документе эти предложения собраны в разделе «Свежие исследования и учебные предложения», препринты помечаются.

Локальное приложение не создаёт базу пользователей и не запрашивает логины или пароли. Если от старой версии остался файл `data/app.sqlite`, текущая версия его не открывает.

## Облачный вход и VPS

Добавленные `Teachers-users` и `Experts-users` подтверждены через API как индексы Vector Store. Для кабинетов преподавателя и эксперта нужен облачный сервис с проверкой учётной записи. Vector Store возвращает фрагменты документов в ответ на поисковый запрос. Данные из этих двух индексов не используются в генерации и не отправляются модели. [Документация Vector Store](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/search/vectorstore)

Compose запускает подготовленный контейнер и привязывает его порт к `127.0.0.1:8501` на хосте. В контейнере приложение показывает экран ожидания облачного входа. Это позволяет проверить сборку и здоровье сервиса перед подключением домена.

```sh
docker compose up -d --build
curl -fsS http://127.0.0.1:8501/_stcore/health
```

Для развёртывания после подключения входа нужны доступ по SSH с текущего ПК, Docker Engine с Compose и HTTPS-прокси с поддержкой WebSocket. Если уже есть прокси, используйте его для домена приложения. При установке Caddy с нуля укажите домен в конфигурации и проксируйте его на `127.0.0.1:8501`. [Docker Engine на Ubuntu](https://docs.docker.com/engine/install/ubuntu/) · [Автоматический HTTPS в Caddy](https://caddyserver.com/docs/automatic-https)

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m pip check
docker compose config --quiet
```

Тесты подменяют ответы Yandex и проверяют выдачу РПД без вопросов, добровольную правку и её повтор, утверждение, содержимое архива и экран сетевого запуска. [Streamlit AppTest](https://docs.streamlit.io/develop/api-reference/app-testing/st.testing.v1.apptest)
