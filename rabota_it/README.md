# IT-вакансии Работа.ру

Пакет принимает полный JSON-снимок из разрешённой выгрузки или договорного HTTPS-источника. Схема ниже описывает вход пакета. Если поставщик использует другую схему, подготовьте преобразование на стороне источника. Убедитесь, что доступ разрешает хранение и передачу данных в LLM. Для производственного запуска нужны документированный адрес или образец разрешённой выгрузки. [Правила и контакты Работа.ру](https://www.rabota.ru/info/)

```powershell
python -m rabota_it import .\vacancies.json
python -m rabota_it search "разработчик Python" --region Москва --technology Docker
python -m rabota_it summary "разработчик"
python -m rabota_it watch https://partner.example/feed --authorised --interval 900
```

Используйте `--database` перед командой, чтобы задать отдельный SQLite-файл. Команда `sync` делает один запрос, `watch` запускает периодическое обновление. Переменная `RABOTA_IT_TOKEN` поддерживает Bearer-аутентификацию. Установите интервал в соответствии с договором. Запросы используют условные заголовки, ограничение частоты в SQLite и `Retry-After`. Предыдущий снимок остаётся доступен после ошибки. Даты последнего скачивания и проверки передаются раздельно.

## Входные данные

JSON содержит массив карточек или объект с ключом `vacancies`. Для локальных файлов `.ndjson` и `.jsonl` поддерживается одна карточка на строку. Каждый успешный импорт заменяет предыдущий снимок. Используйте отдельную базу для каждого источника и передавайте полный набор, включая легитимный пустой массив при отсутствии вакансий. Страницы выдачи перед импортом нужно собрать в полный снимок согласно договорному API.

Карточке нужны `title` и `id` либо URL вакансии Работа.ру. Поддерживаются `employer`, `region`, `description`, `requirements`, `responsibilities`, `conditions`, `skills`, `technologies`, `experience`, `employment_type`, `schedule`, `remote`, `category`, `salary` и даты ISO 8601 в `published_at`, `updated_at`. Даты без часового пояса интерпретируются как UTC. Зарплату можно передать текстом или как объект с `from`, `to`, `currency`, `period`, `gross` и `text`. Для сбора статистики нужны числовая граница и валюта. Группы разделены по валюте, периоду и признаку до вычета налогов.

## Вызов из LLM Business

```python
from rabota_it import BusinessAPI, VacancyStore

api = BusinessAPI(VacancyStore("data/rabota_it.sqlite"))
result = api.handle(operation="search", query="разработчик", technologies=["Python"])
```

Регистрируйте `handle` как инструмент в отдельном вызывающем компоненте. Операции `search`, `get` и `summary` возвращают JSON-совместимый результат. Для `get` передайте `source_id`. Аналитика охватывает только сохранённую выборку. Перед передачей карточек модели используйте доверенную инструкцию обрабатывать содержимое карточек как данные и цитировать URL, если он указан. Встроенный граф проекта не регистрирует этот инструмент автоматически.
