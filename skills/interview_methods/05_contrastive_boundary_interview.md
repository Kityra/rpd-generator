Покажи эксперту только пересекающиеся задачи и навыки из overlapping_items.
Попроси распределить каждый выбранный пункт по одному из трёх полей.

- exclusive_to_primary — пункт относится только к целевой профессии.
- exclusive_to_adjacent — пункт относится только к смежной профессии эксперта.
- shared_core — пункт составляет общую базу обеих профессий.
- handoff_artifacts — названный экспертом результат передачи работы по выбранному пункту.

При сомнении сохрани пробел для методиста. Уточняй только незаполненные запрошенные поля.
